# Forkop Analyzer v0.3.0

## Выбор и проверка серверов

- Добавлен выбор отдельных серверов для Quick, Gaming, Full и Sites. Поиск по имени и tag сохраняет выбор вне фильтра; кнопки «Выбрать найденные» и «Снять найденные» применяются к текущей выдаче.
- Ручной Full больше не обрезает список до 15 серверов: доступны все выбранные узлы, разовый лимит количества и бюджет трафика. План запуска фиксируется до старта worker; счётчик соответствует фактическому плану.
- Для прежних и запланированных запусков сохраняются настроенные лимиты. Full по-прежнему создаёт реальный трафик: по умолчанию до 1 GiB на узел.

## Отмена и история

- Отмена обрабатывается во время подготовки sing-box, проверки конфигурации, измерения задержки, скачивания и проверки сайтов. Дочерние процессы завершаются, блокировка освобождается, готовые результаты сохраняются.
- Results разделён на подвкладки Quick, Gaming, Full и «Доступность сайтов». Поддерживаются клавиатурное переключение, пустые вкладки и сохранение выбранного типа после удаления.
- Добавлена кнопка удаления отдельной отменённой проверки. Backend защищает активные, завершённые и ошибочные запуски; новый RPC доступен только через write ACL.

## Доступность сайтов

- Новый профиль Sites проверяет 15 доменов через отдельный SOCKS instance выбранного сервера: YouTube, Discord, Instagram, Facebook, X, Twitter, LinkedIn, TikTok, BBC, DW, Meduza, TV Rain, RFE/RL, Patreon и Proton.
- DNS проходит через SOCKS, TLS проверяется, редиректы ограничены HTTPS. Production selector не переключается. Результат каждого сайта сохраняется отдельно, доступны история и JSON/CSV.
- Различаются HTTP-ошибки, ограничения, отсутствие поддержки HEAD, сетевые ошибки и достижение лимита редиректов. Код curl 47 корректно отображается и для старых результатов.
- ChatGPT, Claude, Spotify, Netflix и Canva исключены из списка. История прежних запусков сохраняется, включая распознанные антибот-ответы и сообщения о регионе.
- Успешный HTTPS-ответ не гарантирует работу авторизации, видео и всех функций сервиса. Сравнение с прямым подключением не выполняется.

## Интерфейс

- Добавлены локальные SVG-флаги вместо буквенных кодов стран; внешние запросы за изображениями не требуются. Включена MIT-лицензия flag-icons.
- Убрано повторение одинаковых имени/tag и флагов, чекбоксы приведены к единому размеру 18×18.
- Селектор, Sites и Results оформлены в общей светлой/тёмной теме; проверены ширины 320–1680 px.

## Сборка и проверки

- В GitHub Actions добавлен обязательный Linux-прогон с настоящим ucode: тесты выбора серверов, отмены дочерних процессов, Sites и защищённого удаления истории выполняются до сборки APK.
- Workflow использует заметки текущего релиза из репозитория вместо текста предыдущей версии.
- Полный набор backend-тестов и браузерные сценарии пройдены локально. На GL-MT6000 проверены установка исходников, реальные Quick/Sites, сохранность конфигураций и SHA-256 файлов. Сборка APK отдельно проверяет метаданные, зависимости и наличие модулей LuCI.

## Установка

OpenWrt 25.12.x с apk; SDK 25.12.4, контракт Forkop 1.0.5. Скачайте оба APK и SHA256SUMS в один каталог, затем:

```sh
sha256sum -c SHA256SUMS
apk add --allow-untrusted ./forkop-analyzer-0.3.0-r1.apk ./luci-app-forkop-analyzer-0.3.0-r1.apk
/etc/init.d/forkop-analyzer restart
/etc/init.d/rpcd restart
```

Перед установкой дождитесь завершения активного теста. После обновления перезагрузите страницу LuCI через Ctrl+F5.
